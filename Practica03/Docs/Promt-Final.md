Crea un index.html completo y funcional con un Business Model Canvas interactivo del modelo de negocio real de YouTube.

REQUISITOS:

Solo un archivo index.html, sin archivos locales adicionales.
HTML + CSS + JavaScript vanilla; puedes usar CDN.
Usa Achify/Uncodixfy para mejorar la calidad visual del frontend y evitar un diseño genérico de IA.
Diseño moderno, profesional, limpio, responsive y con estética inspirada en YouTube: rojo, negro, blanco y gris oscuro.
Incluye los 9 bloques del Business Model Canvas con información realista y verificable sobre YouTube: creadores, espectadores, anunciantes, Google, YouTube Premium, publicidad, infraestructura, derechos/licencias, socios, costes, etc.
Cada bloque debe tener Vista Simplificada y Vista Extendida.
Agrega selector [Simplificada / Extendida] que cambie el contenido dinámicamente sin recargar.
Agrega hover con tooltip, resaltado y visualización de relaciones.
Los bloques deben mostrar cómo intercambian información/valor entre ellos mediante flechas o conexiones visuales.
Agrega una sección “Ecosistema de YouTube” mostrando las relaciones entre YouTube, creadores, espectadores, anunciantes, socios y Google.
Al hacer clic en cualquier bloque, abre un modal detallado que permanezca abierto hasta pulsar X, hacer clic fuera o presionar ESC.
Agrega botón “Exportar a PDF” usando html2pdf.js vía CDN.
El PDF debe conservar el diseño del Canvas.
Usa JavaScript con una estructura de datos para los 9 bloques, evitando repetir información directamente en el HTML.
Incluye fuentes/referencias oficiales cuando corresponda.
No inventes cifras ni información.
Debe funcionar simplemente abriendo index.html en el navegador.
Revisa al final que no haya errores JavaScript, que todos los botones funcionen y que el diseño sea responsive.

IMPORTANTE:
No generes una imagen, mockup ni pseudocódigo. Implementa directamente la página web completa.
