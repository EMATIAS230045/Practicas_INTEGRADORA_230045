[ROL Y OBJETIVO] Actúa como un Desarrollador Web Frontend Senior y Analista de Negocios. Tu objetivo es crear un Business Model Canvas interactivo, visualmente atractivo y completo para el modelo de negocio real de YouTube, entregado dentro de un único archivo HTML autocontenido (HTML + CSS + JavaScript inline o mediante CDN).

[CONTENIDO DE NEGOCIO]

Completa los 9 bloques del Business Model Canvas con información precisa y real sobre YouTube (creadores, anunciantes, espectadores, infraestructura de Google, YouTube Premium, licencias de contenido, etc.).
Incluye dos niveles de profundidad para el contenido:
Vista Simplificada: Puntos clave e hitos principales.
Vista Extendida: Análisis profundo con detalles operativos, métricas e información técnica/financiera.
[INTERFAZ Y FUNCIONALIDAD]

Selector de Perspectiva: Un botón en la cabecera que permita alternar dinámicamente entre "Vista Simplificada" y "Vista Extendida".
Interacción Hover: Al pasar el cursor sobre cualquier tarjeta o elemento, muestra un tooltip o vista previa destacada con información rápida.
Ventana Modal (Click): Al hacer clic en una tarjeta, debe abrirse un modal/pop-up con el desglose completo del bloque. El modal DEBE permanecer abierto hasta que el usuario haga clic en el botón de cierre ("X") o fuera del recuadro del modal.
Exportación a PDF: Agrega un botón funcional en la parte superior que permita descargar todo el canvas en formato PDF manteniendo el diseño gráfico (puedes usar una biblioteca CDN como html2pdf.js).
[REQUISITOS TÉCNICOS Y ESTILO]

Diseña la interfaz con un estilo moderno, limpio y responsive (inspirado en la paleta de colores de YouTube: rojo, negro, blanco y gris oscuro). Puedes utilizar Tailwind CSS vía CDN.
Todo el código debe estar dentro de un solo archivo index.html listo para abrir en cualquier navegador sin dependencias locales.
Escribe código limpio, comentado y funcional.
