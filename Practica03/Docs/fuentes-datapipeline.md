# 📊 Business Model Canvas — YouTube

## 📌 Descripción

Este proyecto presenta un **Business Model Canvas (BMC) interactivo del modelo de negocio de YouTube**, desarrollado como una página web autocontenida mediante HTML, CSS y JavaScript.

El objetivo es representar de manera visual cómo funciona el modelo de negocio de YouTube, identificando sus principales clientes, propuesta de valor, canales, recursos, actividades, socios, estructura de costes y fuentes de ingresos.

El modelo considera a YouTube como una **plataforma digital de múltiples participantes**, donde interactúan principalmente:

- 👥 Espectadores
- 🎥 Creadores de contenido
- 💼 Anunciantes
- 💳 Suscriptores de YouTube Premium
- ©️ Propietarios de derechos de autor
- 🤝 Socios y empresas
- 🏢 Google / YouTube

---

## 🎯 Objetivo del modelo

El Business Model Canvas se construyó para analizar cómo YouTube:

1. Atrae espectadores mediante contenido audiovisual.
2. Permite a los creadores publicar y monetizar contenido.
3. Conecta anunciantes con audiencias.
4. Ofrece servicios de suscripción como YouTube Premium.
5. Gestiona derechos de autor y contenido protegido.
6. Utiliza infraestructura tecnológica para almacenar, procesar y distribuir contenido.
7. Genera ingresos mediante diferentes mecanismos de monetización.
8. Redistribuye parte de determinados ingresos entre creadores y socios.

# 🏗️ Construcción de los 9 bloques

A partir de las fuentes anteriores se realizó una interpretación del modelo de negocio utilizando la metodología **Business Model Canvas**.

## 1. Segmentos de clientes

Se identificaron los principales grupos que participan en la plataforma:

- Espectadores.
- Creadores.
- Anunciantes.
- Suscriptores de YouTube Premium.
- Empresas.
- Propietarios de derechos.

No todos estos grupos representan necesariamente clientes que pagan directamente por el servicio. Algunos participan como usuarios, creadores, socios o proveedores de contenido.

---

## 2. Propuesta de valor

Se identificaron propuestas de valor diferentes según el participante:

### Para espectadores

- Acceso a una gran variedad de contenido.
- Recomendaciones y descubrimiento de contenido.
- Acceso desde múltiples dispositivos.
- Opciones gratuitas y de suscripción.

### Para creadores

- Distribución de contenido.
- Herramientas de publicación.
- Analítica.
- Monetización.
- Acceso a audiencias.

### Para anunciantes

- Acceso a audiencias.
- Publicidad digital.
- Segmentación y medición.

### Para propietarios de derechos

- Distribución de contenido.
- Herramientas de gestión de derechos.
- Content ID.

---

## 3. Canales

Se consideraron los principales puntos mediante los cuales YouTube entrega su servicio:

- Sitio web.
- Aplicaciones móviles.
- Smart TV.
- Consolas.
- Reproductores integrados.
- YouTube Studio.
- Servicios relacionados con Google.

---

## 4. Relaciones con clientes

Las relaciones se analizaron considerando:

- Recomendaciones automatizadas.
- Soporte para creadores.
- YouTube Studio.
- Estadísticas.
- Programas de monetización.
- Servicios Premium.
- Sistemas de ayuda y políticas.

---

## 5. Fuentes de ingresos

Se identificaron diferentes mecanismos documentados por YouTube:

- Publicidad.
- YouTube Premium.
- Membresías.
- Super Chat.
- Super Stickers.
- Super Thanks.
- YouTube Shopping.
- Transacciones y otros servicios.

## 6. Recursos clave

El análisis considera como recursos necesarios para operar la plataforma:

- Plataforma tecnológica.
- Infraestructura de almacenamiento y distribución.
- Software.
- Datos.
- Sistemas de recomendación.
- Sistemas de monetización.
- Herramientas para creadores.
- Sistemas de gestión de derechos.
- Marca YouTube.
- Ecosistema de usuarios y creadores.

---

## 7. Actividades clave

Entre las actividades necesarias para mantener el servicio se consideran:

- Operación de la plataforma.
- Distribución de vídeo.
- Desarrollo de productos.
- Gestión de contenido.
- Moderación.
- Gestión de derechos de autor.
- Monetización.
- Soporte a creadores.
- Desarrollo de herramientas para anunciantes.
- Análisis y medición.

La existencia de herramientas como Content ID y YouTube Studio permite documentar algunas de estas actividades directamente a partir de la información oficial de YouTube.

---

## 8. Socios clave

El Canvas considera como socios o participantes estratégicos:

- Creadores.
- Propietarios de derechos.
- Empresas y anunciantes.
- Socios de contenido.
- Redes multicanal.
- Google.
- Proveedores y participantes del ecosistema tecnológico.

La relación con propietarios de derechos está respaldada particularmente por la documentación de Content ID.

---

## 9. Estructura de costes

La estructura de costes se planteó a partir de las actividades y recursos necesarios para operar una plataforma global de vídeo.

Se consideran conceptualmente:

- Infraestructura tecnológica.
- Almacenamiento.
- Distribución de vídeo.
- Desarrollo y mantenimiento.
- Seguridad.
- Moderación.
- Gestión de derechos.
- Soporte.
- Operación de servicios.
- Pagos y reparto de ingresos con determinados participantes.

**Importante:** este apartado representa una interpretación del modelo Canvas. No debe interpretarse como un desglose financiero interno de YouTube, ya que YouTube no publica públicamente todos sus costes operativos detallados.

# 🔗 Relación entre los participantes

El modelo representa a YouTube como un ecosistema donde diferentes grupos interactúan.

Una representación simplificada es:

```text
                    ┌──────────────┐
                    │ ANUNCIANTES  │
                    └──────┬───────┘
                           │
                     Publicidad
                           │
                           ▼
┌──────────────┐     ┌──────────────┐     ┌──────────────┐
│  CREADORES   │────►│   YOUTUBE    │◄────│ ESPECTADORES │
└──────────────┘     │   / GOOGLE   │     └──────────────┘
       │             └──────┬───────┘             │
       │                    │                     │
    Contenido          Plataforma             Visualización
       │                    │                     │
       └────────────────────┼─────────────────────┘
                            │
                            ▼
                   ┌─────────────────┐
                   │ PROPIETARIOS DE │
                   │    DERECHOS     │
                   └─────────────────┘
```

Esta representación busca explicar que el valor de YouTube no depende únicamente de un grupo, sino de la interacción entre diferentes participantes.

# ⚠️ Consideraciones sobre los datos

Este Business Model Canvas **no representa información financiera interna confidencial de YouTube**.

Cuando una cifra específica o información interna no está disponible públicamente:

- No se inventó.
- Se utilizó una descripción cualitativa.
- Se indicó cuando una conclusión corresponde a una interpretación del modelo Canvas.
- Se priorizaron fuentes oficiales.

Las condiciones, porcentajes, requisitos y características de los servicios pueden cambiar con el tiempo. Por ello, la información del Canvas debe considerarse una representación del modelo de negocio basada en las fuentes consultadas y en su estado disponible al momento de elaboración.

# 📝 Nota metodológica

El Business Model Canvas fue elaborado mediante la combinación de:

**Fuentes oficiales → identificación de actores → identificación de actividades y recursos → identificación de mecanismos de monetización → identificación de propuestas de valor → organización de la información en los 9 bloques del BMC.**

Por lo tanto, el Canvas no pretende reproducir un documento interno de YouTube, sino **modelar públicamente su funcionamiento empresarial a partir de información disponible y verificable**.
